- 搭配文件：[後端計畫](./PERSONAL_ANALYSIS_BACKEND_PLAN_2026-10-21.md)、[原產品計畫](./PERSONAL_ANALYSIS_AND_PRACTICE_PLAN_2026-10-11.md)。

## 怎麼批閱

把想選的 `[ ]` 改成 `[x]`，或直接填「批註」。也可以在對話回覆 `U03 選 B，補正解不算整題確認`，不需要會改 Markdown。

每小題原則上單選；標示「可複選」的例外。沒有適合的選項可直接寫替代方案。**空白表示尚未決定，不是同意由 agent 代選。** 選項列出的是取捨，沒有預設核准的推薦答案。

只需先處理第一批，第二、三批可分階段決定。資料表、判分、冪等與索引等後端實作已另行規劃，不需要在此逐欄核准。

## 不用重新決定的共識

- 上傳時 AI 同次辨識題文、題型、選項、原作答、正解與可能錯因；讀不到就空白。
- 題目只有「AI 辨識／使用者已確認」兩種確認狀態，不強制逐欄確認。
- 原題抽題從本人上傳與已存入題選取；同輪不重複。
- 測驗先顯示文字與選項，隱藏舊筆跡、原作答、正解與訂正筆記。
- 有「檢視原圖」按鈕；圖片初始放大置中，可移動縮放，允許圖上有答案。
- 有正解的選擇題自動判分，複選集合全對；其他題型或缺正解可按「這次答對／這次答錯」。
- 缺正解可補齊，也可先不補；略過不算作答。
- 每次提交保留獨立紀錄；訂正狀態不等於重作答對／錯。
- 科目分析要有樣本數、時間、資料組成與原題依據；沒有重作紀錄不能說進步／退步。
- Pro 生成新題不放進第一版。

## U03｜「儲存修改」是否等於「整題已確認」？

原計畫寫成「修改後儲存＝confirmed」，也把「只補正解」算整題確認；這是目前最需要釐清的地方。你已同意只有兩種狀態，但尚未明確核准每一種操作的含義。

- [ ] A. 沿用原計畫：修改任何欄位後儲存，就代表確認整份資料；只補正解也一樣。
- [ ] B. 儲存與整題確認分開：改一欄不代表看過其他欄位，另按「確認目前資料」。尚未整題確認時仍顯示「AI 辨識」。
- [ ] C. 提供「儲存」與「儲存並確認」兩種操作，使用者當次選擇。

若採 B 或 C，對**原本已確認**的資料再修改：

- [ ] 儲存即維持已確認，因為是本人主動修改。
- [ ] 改後先回到 AI 辨識狀態，需再次整題確認。
- [ ] 儲存時讓使用者選是否維持確認。

兩種狀態不變；B／C 中「AI 辨識」的說明會是「尚未整題確認，可能已有人工修改」，避免誤認每一欄都是 AI 原值。

批註：

## U04｜重新辨識後，怎麼採用新結果？

後端固定先保存候選，不直接覆蓋已確認內容。採用時再檢查資料有沒有被其他裝置修改。

- [ ] A. 顯示新結果預覽，整份採用或取消；操作少。
- [ ] B. 新舊欄位並排，選擇要採用的欄位；控制較細，畫面與操作較多。
- [ ] C. 預設只補空欄；已有資料若要改，另進編輯。

採用後的確認狀態：

- [ ] 採用代表已看過並確認，顯示「使用者已確認」。
- [ ] 採用仍屬「AI 辨識」，另行整題確認。

批註：

## U05｜存入題更新來源後，個人資料如何呈現？

來源更新可能改動題文、選項或答案。歷次作答一定保留舊判分依據；本人原作答、錯因、筆記不被來源作者覆蓋。

- [ ] 更新來源時一併開啟新舊資料確認，當次決定是否採用。
- [ ] 先保留目前個人題目，在詳情提示「來源有新版」，之後再處理。

未採用前是否仍可用目前版本抽題：

- [ ] 可以，顯示目前使用的版本資訊。
- [ ] 暫不納入新一輪抽題，處理後再恢復。

批註：

## U15｜訪客第一版能用到哪裡？

這一題會影響離線、額度與登入後資料歸屬，需要在第一階段決定。

- [ ] A. 新增的確認／練習／個人分析只開放登入帳號；維持既有訪客功能。
- [ ] B. 訪客可本機練習與記錄，個人 AI 分析要登入；增加本機資料與移轉流程。
- [ ] C. 訪客也可個人 AI 分析；需另定匿名額度、防濫用及清除規則。

若開放訪客記錄，登入時：

- [ ] 詢問是否將本機記錄匯入本次登入帳號。
- [ ] 不移轉，訪客資料維持獨立。

批註：

## U16｜一張圖片包含多道題目時怎麼辦？

目前以單張上傳建立一筆題目。若圖中有多題，將數個答案混成一個欄位會影響判分與分析；自動拆題是額外範圍，不能在後端默默決定。

- [ ] A. 第一版維持一筆資料是一個練習單位；多題圖片用整體自評，不做逐小題自動判分。
- [ ] B. 讓使用者指定本次要整理哪一題，其餘保留在原圖；逐次另建題目。
- [ ] C. 第一版就要拆成多筆題目；需再設計拆題確認與圖片共用流程，延伸工期。

# 第二批：開始抽題頁與作答流程前

## U06｜一輪幾題？要讓使用者調整哪些抽題偏好？

後端已規劃同輪去重、有限候選與可調政策，以下產品數值不自行設定。

**A. 題數**

- [ ] 固定題數，先求流程簡單。每輪：____ 題。
- [ ] 開始前可選題數。提供：____／____／____ 題；預設：____ 題。
- [ ] 持續練習直到自行結束；需另定本輪何時重置去重範圍。

**B. 抽題偏好**

- [ ] 只提供一種自動混合：近期再錯、久未重作、無紀錄與其他題目。
- [ ] 讓使用者選「綜合／近期再錯優先／久未複習優先」。
- [ ] 讓使用者自行調比例；操作較多。

若有比例偏好，請填；留空代表之後仍需核定：________________。

**C. 已封存題**

- [ ] 預設不抽，可另外勾選。
- [ ] 一律不納入抽題。
- [ ] 納入，與未封存題同樣處理。

## U07｜原圖怎麼開？放大多少？

已確定有「檢視原圖」，初始放大置中，可拖曳縮放，不遮答案。待決的是容器與初始閱讀比例。

- [ ] A. 覆蓋式檢視，關閉後回到題目；原圖可用空間較大。
- [ ] B. 題目內展開原圖；題文與作答仍在同一頁。
- [ ] C. 寬螢幕並排、窄螢幕覆蓋；需明確定義兩種版面。

初始倍率：

- [ ] 先做可比較的原型，再由我選；不先固定倍數。
- [ ] 相對適合圖片的倍率為 ____ 倍。

每次重新開原圖：

- [ ] 回到初始置中。
- [ ] 在同一題保留上次移動／縮放位置。

## U08｜自評、補答案與判錯修正，先後怎麼走？

**A. 非選擇題／缺正解時**

- [ ] 直接提供「這次答對／這次答錯」，查看答案或原圖是選用。
- [ ] 先按「完成作答／查看答案」，下一步才出現自評按鈕。

**B. 缺正解的補齊入口**

- [ ] 作答時就顯示，可先補再判分。
- [ ] 自評後再提供補齊；不打斷這次作答。
- [ ] 兩處都提供。

**C. 有正解但使用者發現判錯不合理**

- [ ] 顯示「答案有誤」，修正正解後可選擇更正本次結果。
- [ ] 測驗中只提出問題／標記，回題目詳情修改；本次更正另操作。

更正只影響明確指定的那次事件，不批次重算全部歷史；補正解是否整題 confirmed 依 U03。

## U09｜重作時需不需要新的手寫草稿？

舊筆跡隱藏已確定，但還沒決定本次練習的新筆跡如何保存。這會影響 canvas 與資產管理，不能直接沿用舊訂正筆跡覆寫。

- [ ] A. 第一版只做答案輸入／自評；手寫可在紙上完成，不新增草稿功能。
- [ ] B. 提供本輪暫存草稿，結束後不併入訂正筆跡。
- [ ] C. 每次作答保存獨立草稿，可在重作歷史回看；增加儲存與同步範圍。

若選 B，重新整理／中途離開是否要保留暫存：________________。

**A. 下一題**

- [ ] 判分／自評後停留，按「下一題」繼續。
- [ ] 顯示簡短結果後自動前進，仍可回看。

**B. 中途離開**

**A. 預設期間**

- [ ] 最近 30 天。
- [ ] 最近 90 天。
- [ ] 本學期，起訖日由使用者設定。
