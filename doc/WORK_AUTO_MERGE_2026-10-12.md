# 作業自動合併：實作與驗收

## 範圍

- 我上傳、我存入、共用中沿用同一個同步控制器核心。筆跡與筆記仍各有自己的版本號；共用中只更新本人作業，來源作者更新其原題的同一份作業。
- 不修改 D1 schema，不新增輪詢，也不採用完整 CRDT。此功能無 migration；先前內文複製的 0008 仍是獨立發布前置要求。

## 本機資料與合併

- 草稿保存待送內容、各欄位版本、最後成功同步的 baseInk/baseNotes，以及已送出但未確認的請求；既有草稿 key 不變。
- 新筆畫含 UUID；向量擦除切成的新片段各有自己的 UUID，未碰觸的筆畫保留 ID。舊筆畫不必重寫或 migration。
- version/CAS 不移除。發生 CONFLICT 才 GET 最新作業，比較共同版本、本機與雲端。存入／共用的衝突讀取不下載其他人的參考筆跡。
- 相同內容視為已確認；僅一邊修改時採用該修改。兩邊新增筆畫時，只合併原筆畫與遮罩未改、座標一致、所有新增筆畫有 ID 的內容；相同 ID 只加入一次，不同內容的同 ID 或重複 ID 拒絕合併。目前編輯器產生的單筆推導區高度記錄，其 atY 是螢幕尺寸，不是向量位移；不同裝置的這項差異不誤判為座標衝突。
- 筆記以 Unicode 字元找出各邊的變更區間；互不接觸的區間合併。區間重疊、同處插入，或多處修改被保守判定為一個重疊區間時，要求選版本，不猜測順序或意思。
- 擦除、清空、原筆畫修改、座標／展開位置變更與另一邊修改並存時，保守要求選版本。沒有共同版本的舊草稿也要求選版本；內容與雲端相同則直接確認。
- 雲端回應期間新增的本機修改使用最新 pending 內容，不以送出時的舊副本蓋掉。回應遺失可確認已送版本或依穩定 ID 去重，再同步後續修改。
- 有筆畫／中文組字進行時，衝突合併等待操作完成。文字保留焦點並調整游標；可安全重設的復原紀錄保留遠端新增筆畫，不能撤銷雲端新增內容。無法重設的歷史清除，禁止以舊版備援復原刪除遠端內容。
- 連續三次自動處理仍有版本爭用後停止自動重試，保存草稿並顯示同步失敗；使用者可手動重試。權限失效、題目消失或集合 generation／作業對象變更不自動覆蓋。

## 無法合併時的 UX

1. 自動開啟內建對話框，標示題號與來源，並列本機／雲端筆跡、筆畫數與文字筆記；多題衝突依序開啟，避免多個視窗同時攔截焦點。筆跡預覽涵蓋完整座標高度，較長內容可自行捲動。
2. 提供「保留雲端版本」「保留本機版本」及下載本機作業。
3. 選擇前重新讀取雲端；內容若已不同，更新預覽並要求重新確認，尚不寫入。
4. 兩種選擇先備份兩份內容。保留雲端先清除可重播草稿，再重建當題編輯器，清除已捨棄的畫布／文字／歷史與尺寸狀態。
5. 保留本機只更新使用者改過的欄位，未修改的欄位沿用最新雲端；本機預覽也呈現這些未修改的最新欄位。以最新 CAS 版本重新送出，不跳過權限檢查。
6. 備份／本機儲存失敗時，不宣稱完成。關閉提示保留草稿與待核對狀態，可由題卡重新開啟。
7. 此處的雲端作業指同一使用者的作業；其他貢獻者各自的筆記與筆跡不參與合併或覆蓋。

## 驗證與剩餘邊界

- `tests/work-merge.test.mjs` + `tests/owned-work.test.mjs`：23 項，含去重、擦除／座標拒絕、Unicode、操作途中修改、重新載入基準、回應遺失、兩種選擇、備份、爭用停止與正常存檔零額外 GET。
- `tests/work-merge.browser.py`：390／1280px、三種來源，實際畫布與筆記合併、復原／重作、焦點／游標、自動彈窗、彈窗後雲端更新、兩種選擇與重新載入；另驗證兩題草稿衝突只顯示一個視窗，關閉後顯示下一題，兩份草稿都保留。
- 既有採用雲端／尺寸／草稿回歸、本人原題／共用作業後端隔離、TypeScript、正式建置／SW 與 PWA 檢查。
- 合成 API／桌面瀏覽器的手機尺寸驗證，不取代實體 iPhone／iPad 的 Apple Pencil、中文鍵盤和雙裝置驗收。
- 本機儲存會多保留共同版本；空間不足會顯示本機儲存失敗，仍可下載記憶體草稿。備份清理與完整跨裝置版本歷史不在本次範圍。
