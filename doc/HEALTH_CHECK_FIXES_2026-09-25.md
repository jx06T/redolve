## 已修正

| 類別 | 修正 |
| --- | --- |
| 帳號資料隔離 | 私人題目及圖片只能由擁有者讀取；公開分享維持獨立唯讀路由；分享權限不再允許他人寫入筆跡。 |
| PWA 快取 | Service Worker 只快取靜態殼層與資源，升版清理舊 API／圖片快取；登出時再次清除舊私人快取。 |
| OAuth 與 Session | 核對 state cookie，限制回傳 origin，改用可撤銷的 HttpOnly session cookie；URL 不再夾帶 JWT／姓名／email；登出撤銷 session；移除未驗證 ID token 的舊入口。 |
| 跨帳號離線同步 | 待同步操作記錄擁有者；舊佇列重播前查驗題目擁有者；登出保留尚未同步的本機草稿。 |
| 訪客離線收題 | 圖片在 AI 請求前存入 IndexedDB；分析失敗保留待處理題目，連線後重試；儀表板與搜尋可讀取本機資料。 |
| 隱私揭露 | 明示訪客選擇 AI 分析時，圖片會送往後端及 Google Gemini。 |
| 分享 | 新增有效期限、已建立連結列表與撤銷操作；公開分享內容禁止索引與快取，撤銷後圖片不再提供可保存一天的回應。 |
| 安全與穩定 | 補 CSP、來源白名單、Cloudflare rate limit binding；移除 isolate 記憶體限流及缺密鑰時的固定 JWT secret。 |
| 首次使用與說明 | 空儀表板提供三步引導；快捷鍵說明補三指重做；上傳說明補 HEIC／HEIF。 |
| SEO 與文件 | 修正正式網址、robots／sitemap 衝突、登入與授權描述及部署步驟；分享內容保留通用社群預覽，避免在預覽中揭露題目。 |

## 上線前操作驗收

正式 D1 已執行 `0001_auth_sessions.sql`。部署新 Worker 後，舊登入憑證會失效，使用者需重新登入。請用兩個測試帳號、訪客離線資料及分享連結驗收資料隔離、同步、期限和撤銷。正式環境及實體裝置結果尚未取得。

健檢提及的分享密碼、指定收件人、單次存取與檢視紀錄屬於新增產品功能；目前的分享仍是持有連結即可查看。首頁導覽的資訊密度屬於產品取捨，本次新增首次使用引導而未改動已確認的 iPad／手機導覽操作。
