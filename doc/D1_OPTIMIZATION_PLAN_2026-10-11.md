## 已實作契約

### 空白查詢

- `q.trim()===''` 且 `browse=1`：組合原有來源／分類／標籤／狀態／權限篩選，按建立時間、新到舊排序。
- 不組合 `fts_hits` CTE、`items_fts` JOIN、逐題 `MAX(rowid)`、`LIKE` 搜尋條件或相關度運算。`relevance_score=0`，回應格式維持相容。
- 單一來源按 `created_at DESC,id DESC`；多來源保留 `created_at DESC,origin,id DESC` 的穩定順序。移除單一來源的常數 origin 排序，讓現有索引可在取得一頁後停止。
- 沒有 `browse=1` 的空白搜尋仍回傳空結果。非空關鍵字保留原搜尋行為。
- 全部路徑保留本人、目前集合權限、貢獻者資格、圖片 ready、generation、訂閱與授權期限檢查。訂閱仍不能取代觀看權限。
- 存入題仍以已取得 snapshot 與私人工作區讀取，來源撤權或刪除不會使存入版本消失。
- 一般共用題回應保留原有授權筆記摘要；`metadata_only=1` 不聚合用於顯示的共用筆記。空白存入瀏覽不聚合參考層筆記作搜尋評分。

### 搜尋頁精簡投影

- 空白輸入仍使用 `/api/search?browse=1` 作分頁列表，並非全文搜尋；保留目前來源、分類、狀態、標籤及權限。只有提交非空關鍵字才套用文字搜尋條件。
- `projection=compact`：回傳圖片存取所需 ID、來源與分類等清單欄位；不回填 `problem`，不傳筆跡／筆記／標籤資料。圖片由原本授權圖片 API 載入。
- 上傳題不執行完整 `items` hydration；空白存入列表不 JOIN `personal_workspaces`；空白共用列表不聚合顯示筆記。非空查詢仍可搜尋有權限的筆記／標籤，不因省略回應欄位而漏掉命中。
- `projection=full` 為 API 預設，相容原客戶端。詳細檢視與刷題維持完整資料流程；metadata 大綱仍以 `metadata_only=1` 取得。
- 前端快取鍵包含精簡／完整模式，切換到詳細檢視會取得完整題目，不能使用精簡資料代替。簡單檢視不覆寫刷題的完整題目 store。
- 搜尋頁不查題目所屬共用集；上傳／存入搜尋不載入未使用的可貢獻集合清單。共用中搜尋仍取得集合選單，刷題仍保留加入集合與已共用標示。
- 訪客只有空白字元時視為本機列表，與後端 trim 行為一致。

### 清單短期快取（2026-10-11）

- 模組：`src/services/listCache.ts`。普通物件／函式介面，不增加套件。只存在目前分頁的 JS 記憶體；重新整理網頁後重新取得資料。
- 範圍：`/api/search` 的 `scope=mine` 且 `origin=owned|saved`，含空白瀏覽、關鍵字、刷題、搜尋及已選科目的 metadata 大綱。訪客仍直接查本機 IndexedDB。
- 鍵：目前帳號的獨立快取世代＋API 位址＋排序後參數，包含来源、關鍵字、分類、狀態、標籤、集合條件、排除封存、offset、limit、metadata 與 compact/full。關鍵字 trim，沒有改寫大小寫或中文搜尋語意。
- 成功收齊 JSON 後起算 **40,000ms**；命中、重新 render、回到頁面、追加下一頁都不延長既有頁的期限。合併清單以最早一頁的時間決定是否可整份沿用。
- 同鍵未完成 GET 共用一個請求。單一畫面取消等待不取消其他消費者；帳號切換會中止所有舊帳號請求。錯誤不儲存；重試可重新請求。
- 成功 POST/PUT/PATCH/DELETE 經 `api.ts` 或 `sharingApi.ts` 清除個人清單與導航結果。先採保守的整批失效，避免遺漏跨來源影響；未新增重拉所有清單的背景動作。失敗寫入不被當成已成功修改。
- 寫入發生於 GET 途中時，舊世代結果不能回填快取，改取新世代資料；回應保留取得時的世代，不能因 UI 較晚收到而被誤認為新資料。
- 手動重新套用篩選／`redolve:library-refresh` 強制失效後載入；既有 Logo／瀏覽器重新整理會重建記憶體。到期沒有 timer／輪詢；下一次使用才取得最新資料。
- `setCurrentUser`／登出清除舊帳號資料與返回快取；不能 A→B→A 重新沿用 A 的舊結果。
- 刷題／搜尋返回快取限 20 範圍，API 快取 LRU 限 40 頁。新頁成功才記錄；不是將空白載入狀態視為有效快取。保留已載入分頁及既有捲動／anchor 還原。
- 共用中每次進入仍經後端驗權，取得目前集合／個人版本；確認未變更才沿用 40 秒內清單，見下節。公開探索、延伸題目與一般觀看查詢維持原路徑。
- 筆記／筆跡儲存與共用／存入題卡內容 GET 仍走原同步流程；返回上傳題卡時優先保留 store 中較新的本機內容，不用快取覆蓋待同步筆記。
- HTTP 傳輸維持 `cache: no-store`；未將私人 API 寫入 Cloudflare 公共快取、Cache API 或 service worker。集合權限、會員關係、訂閱／個人檔案清單及 Dashboard 不在本次 40 秒快取範圍。
- 接受的延遲：別的裝置新增／更改個人題目，可能到下一次到期使用或手動整理才反映；正在停留的清單不會因 40 秒到期自動重排。

驗證：`tests/list-cache.test.mjs` 覆蓋期限、去重、取消、帳號、寫入競態、LRU、實際 API adapter；`tests/list-cache.browser.py` 覆蓋桌面／手機來源與投影切換、續頁保留、到期不輪詢、手動整理、寫入後返回與共用驗權。正式 D1 總量減少比例仍需部署後量測；快取命中的清單請求才會省下該次 HTTP／Worker／D1 工作。

### 共用中條件式清單驗證

- 只限已登入、`scope=shared&contributing=yes&collection_id=...`，不含 `subscribed=yes`。不擴大公開／觀看者／延伸題目快取範圍。
- 新增 0005：`collection_search_versions` 記錄集合版本、`collection_search_user_versions` 記錄個人進度／已存入狀態版本、`collection_search_cache_config` 控制 schema readiness。28 個 DB trigger 讓寫入與版本計數在同一資料庫操作內完成。
- 集合版本涵蓋集合設定、成員授權、題目增刪／generation／來源 metadata／標籤、共用筆記／筆跡、作者名稱、官方課綱及圖片狀態。私人原題筆跡／筆記不因共用清單而外洩；不將其當作共用內容。
- 個人完成／封存／複習次数及存入／移除只更新該使用者的集合版本。共用筆跡／筆記仍會更新集合版本；題卡明細 GET 與同步未加入快取。
- 每次請求先於單一查詢中取得目前 contributor 權限與版本，不掃題目或筆記。另計算集合內已到期、未撤銷的 contributor 授權數，處理無 DB 寫入的自然到期。
- `ETag` 綁定帳號、集合／個人版本、到期授權狀態、搜尋契約版本與完整 query（含 offset、projection、metadata、tag、status 等）。`If-None-Match` 相符才回 304，跳過完整搜尋。CORS 放行 conditional header 並 expose 兩個版本 header。
- `X-Redolve-Collection-Version` 提供同帳號／集合的 opaque 版本，用於確認已載入多頁是同一版本。只在首頁已驗權且 304 後還原該版本的合併清單，不能先展示未驗權的舊題目。
- 40 秒期限自最初完整回應起算，304 不延長。驗證期間過期則再取得完整清單；失敗不回退舊清單。不同版本混合追加會標示重新套用篩選，不能當作完整有效的返回快取。
- 撤權沿用目前 contributing 搜尋契約：200 空清單、無 ETag；不給 304。原本已驗證的清單在續頁時失去版本標記，重新讀取首頁並替換舊列表，避免保留已撤權題目。未登入仍拒絕。Missing migration／ready=0 時正常完整查詢，不啟用驗證；其他 DB 錯誤不掩蓋。
- 不新增輪詢／定時重排；仍需重訪、手動重新整理或既有本機修改觸發新查詢。記憶體只有本分頁；切帳號、成功寫入及手動整理仍整批失效。
- 代價：首次／版本已改變的搜尋多一條驗權版本查詢；有影響的寫入多版本計數寫入。來源已加入 N 個集合時需更新 N 個集合，官方課綱變動則失效所有集合；圖片狀態寫入需查來源引用。部署後觀察 rows_written，不宣稱總成本無條件下降。

本地合成 219 題、同一集合、2 位 contributor、compact 首頁：完整搜尋＋版本查詢共 **1,758 rows_read**；未變更驗證 **6 rows_read**（均排除登入驗證）。這組資料的 304 不查完整題目／共用筆記；授權人數增加時驗證成本仍可能增加，不是所有帳號的固定成本。

驗證：`tests/shared-search-cache.test.mjs` 測實際 route／D1 trigger、重複 migration、權限撤銷／自然到期、標籤／筆記／名稱／課綱／圖片／generation、個人進度隔離、查詢／帳號版本隔離及缺 schema fallback；`tests/shared-search-cache.browser.py` 測桌面／手機 304、分頁還原、更新／撤權／網路失敗、到期與手動重整。
