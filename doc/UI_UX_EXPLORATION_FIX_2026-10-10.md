## 入口與關係

```text
總覽 → 公開探索 → 查看公開集合／題目
                  → 明確訂閱 → 延伸題目（保留本題焦點）
延伸題目 → 選擇已訂閱集合 → 題圖與四項工具
設定 → 個人檔案 → 收到的邀請 → 接受取得權限
                         → 觀看集合 → 另外設定訂閱
                         → 貢獻者可管理共用集
```

- 取得權限、訂閱、存入是三個獨立操作。觀看／接受邀請／存入都不會自動訂閱。
- 取消訂閱移除觀看選單關係，不刪除已存入版本與私人訂正；公開來源仍可從探索觀看。
- 建立者沿用後端規則，不提供訂閱自己集合的操作；從自己的刷題與管理區使用。
- 訂閱狀態尚未讀取成功時暫停訂閱按鈕，避免錯誤顯示相反操作；清單失敗可重試。
- 單題工具維持既定範圍；訂閱按鈕屬於集合區，非新增題目訂正功能。

## API 與權限

- `GET /collections/:id/candidates`：只列目前使用者原題、ready 資產、尚未加入的題目；新增 `question_text`。
- `GET /collections/:id`：僅可貢獻者取得 `question_text` 管理摘要；一般／匿名觀看者不回傳該欄位。
- OCR 依原題 ID＋作者 ID 查最新 FTS row；不使用 `typed_notes`。
- `GET /public/items`：增加本人是否建立該集合的 boolean，仍只列 active＋public＋listed 與目前有效貢獻。
- `POST /invitations/accept`：保留 token 入口；新增 `{ invitation_id }`，兩種方式皆比對目前登入帳號 email、未接受、未撤銷、未過期與集合生命週期。
- 接受邀請只建立 grant，不建立 subscription。沒有新增匿名書寫權限。
