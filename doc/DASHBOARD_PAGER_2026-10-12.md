# 總覽左右滑頁：實作規格

## 版面

- 標語／接續刷題屬於第一頁，與統計一起左右滑走；其他頁使用完整滑頁區高度。全站導覽保留。
- 三格統計卡右緣使用對應圖示的淡漸層：總錯題淡紫、已完成淡綠、待解決淡橘，保留灰白底色。
- 卡片外緣與標語對齊，不加滑頁外框。底部列出面板名稱與目前選取狀態；不顯示重複的 1/4 頁數，不加側邊箭頭。
- 寬度 >=768px：兩頁。
  1. 複習進度：保持心流標語，總錯題／已訂正／待解決橫排三格，未分類提示；下方科目訂正率與最需複習單元 Top 5，欄寬 2:1。
  2. 日常工具：左待辦，右上倒數／右下公開探索；左右等高，右側高度 2:1。
- 寬度 <768px：四頁。
  1. 複習重點：保持心流標語、緊湊的三格統計、未分類提示與 Top 5。
  2. 各科進度。
  3. 待辦。
  4. 倒數／探索。
- 隱藏待辦時移除手機待辦頁；寬版日常工具右側擴滿。隱藏倒數時探索填滿其所在欄。
- 訪客／新使用者說明在第一頁可展開。有更新才提供共用／訂閱動態按鈕，於日常工具頁開啟 AppDialog。
- 內容超量於各卡片內部上下捲動；低高度／軟鍵盤導致不足時，外層可上下捲動，不截斷操作。

## 操作與狀態

- 原生 overflow + CSS Scroll Snap；觸控可從面板中間直接左右滑，不需按鈕。下方面板名稱可點擊；名稱列與滑頁區支援方向鍵、Home、End，尊重 reduced motion。
- 待辦一般文字列允許滑頁，點擊後進入編輯。輸入框保留直向捲動與文字選取，不搶橫向游標操作；勾選及刪除按鈕維持原功能。
- 所有面板保留掛載；切頁／旋轉不清空新增草稿、不重設內部捲動，也不發送 API。離開含已聚焦編輯器的面板時 blur，沿用既有編輯提交行為。
- 未顯示的內容 inert + aria-hidden，避免鍵盤進入畫面外按鈕。選取狀態由面板名稱的 aria-current 表示。
- 本裝置 localStorage：`rdv:dashboard:panel:v1:<account>:wide|compact`；帳號隔離，寬窄版分別記憶。儲存不可用時退回記憶體。
- URL `#dashboard-overview|subjects|todos|tools`；入口明確 hash 優先，其餘用本機記憶。切換使用 router replace，不增加瀏覽歷史。寬版 subjects 對應 overview、todos 對應 tools；手機隱藏待辦時回 overview。
- 偏好僅記最後面板。未送出的新增文字在滑頁／旋轉保留；跨重新整理仍沿用小組件既有規則，不把尚未按新增的文字當成已建立待辦。

## 資料與發布

- 後端最需複習單元由 Top 3 改為 Top 5；同數量按 topic ID 排序。訪客本機統計同樣改為五筆。
- 保持原有查詢與帳號範圍，不新增 D1 查詢；面板記憶不送 D1，無輪詢。
- 不新增 migration、binding 或 secret。首頁小組件仍需既有 0009 schema；本地已完成，正式依 HOME_WIDGETS 發布指南確認。
