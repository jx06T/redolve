## 1. 已確認的流程與本次修正

| 項目 | 決定 |
| --- | --- |
| 入口 | 獨立練習／分析入口，進入後選科目；題目右上工具列圖示開啟辨識資料彈窗 |
| 未分類 | 分析不納入；原有閱讀、訂正與整理流程維持 |
| 修改／補正解 | 儲存即整題 confirmed；空欄位仍可存在；再次人工修改維持 confirmed |
| 手動重辨識 | 可編輯的新結果預覽，整份採用或取消；採用即 confirmed |
| 舊題 | 手動觸發重新辨識或人工整理後才加入文字抽題，不批次自動呼叫 AI |
| 練習 | 3／5／10 題，預設 5；自動混合且保留後端可配置性；封存題預設不抽，可勾選 |
| 原圖 | 所有螢幕尺寸皆使用懸浮彈窗；預設置中放大 1.5 倍，可拖曳縮放，不切換左右分欄。縮放控制浮於圖片右上角，不另佔一列；倍率顯示隨實際縮放更新 |
| 作答 | 所有題型先查看答案；此時可修改／補齊正解。選擇題顯示自動判分預覽，再按「確認結果並下一題」；其他題型按「這次答對／這次答錯」 |
| 前進 | 確認結果後先保存一筆獨立作答，成功即自動下一題；本機保存失敗留在原題重試。只查看答案或略過不計次；修改正解後採用新版本判分，不建立中間的更正事件 |
| 操作列 | 固定於畫面底部並避開手機導覽；各階段維持單列，空間不足可橫向滑動。答對用綠色、答錯用紅色並搭配文字／圖示，主要動作用品牌紫色。原圖與修改資料使用彈窗，不提供直接離開練習的原題連結；未提供重新辨識能力時不顯示該按鈕，練習內仍可手動修改正解 |
| 草稿與離開 | 本輪提供暫存草稿；離開不保留未提交答案、草稿及整輪進度，不提供續做。覆蓋先前 U09「離開仍保留」選擇 |
| 已提交事件 | 仍永久性落地到既有事件保存流程；離開不撤銷提交，也不刪尚待同步的 outbox。長期刪除遵守個人資料政策 |
| 來源更新 | 在既有刷題頁手動處理；分析頁不新增更新來源步驟，也不自動取最新共享來源 |
| 分析 | 先顯示統計／既有報告，手動產生；只顯示截止時間，不主動彈出有新資料提醒 |
| 報告內容 | 先弱點／可能錯因，再建議練習；資料組成摘要可展開；直接開始建議原題組 |
| 錯因修改 | 從報告引用回原題修改，已產生報告保持原樣 |
| 訪客 | 第一版新增功能限登入帳號；既有訪客功能不變 |

草稿只存在本輪記憶體；重新整理／關頁後無續作保證，不能為恢復草稿再加本機持久化。暫時切到背景而頁面未卸載，不必主動清除記憶體。退出提醒的呈現仍屬 UI 未定事項，不預先新增確認彈窗。

## 2. 裁切拆題：依本次描述整理的草案

原本一筆題目 Q 的圖片包含 A、B、C。使用者指定 A 留在原題，另框出 B、C，預覽後一次儲存：

- 原題 Q 保留題目識別，但目前顯示與題文改為 A。
- B、C 各成為獨立的個人題目，可分別分類、辨識及作答。
- 題庫目前顯示 A、B、C 三題，不另外顯示一題重複的 ABC。
- 保存裁切前版本與原資產作歷史依據；不是直接銷毀原圖。

這是對「把 B、C 移出，原題剩 A」的具體化，尚不是完整核准的裁切操作設計。誰留在原題由使用者指定，不以畫面排序猜測。跨題共用題幹／圖表可能要在裁切範圍保留，不要求矩形絕對不重疊。

### 後端必須做到

1. 建立拆題關聯、來源版本及裁切座標；A 的更新與 B／C 的建立原子提交並可冪等重送。R2 新資產先準備，D1 失敗後清理未引用資產，不留下半套題目。
2. 原本 ABC 的答案、確認狀態及錯因不能無條件複製三份；各裁切結果分別取得題文與答案，人工確認範圍需對應到新內容。舊 confirmed 保留在歷史，不代表新裁切內容已確認。
3. 原本對整張 ABC 的作答仍是整張圖片的歷史，不能算成 A／B／C 各做過一次。以新的作答單位識別區分拆題前後；按新單題計算進步與最近結果時不混用。歷史整張事件仍可在其原期間追溯，報告另列拆題前事件數。
4. 原題已被他人存入時，別人的保留版本不變；對存入題拆分，只改自己的個人副本，不改共享來源，也不因拆分失去來源的再分享限制。
5. 本案要補裁切專用資料契約，不能硬塞到既有「來源更新必須同一張原圖」端點。它是個人內容衍生操作。

### 筆跡處理提案，待批閱

先保存完整舊筆跡，預覽時將各裁切框中的向量筆跡裁剪、平移到各題座標；跨框筆劃按區域分段。沒有幾何位置的文字筆記不自動分派。不能把 ABC 的整份筆跡縮小貼到三題，也不能以圖片像素擦除取代向量筆跡。

若此範圍過大，替代草案是新裁切題先不帶筆跡、舊筆跡留在原始版本。兩者尚未決定，實作前用裁切預覽確認，避免無聲遺失訂正內容。

## 3. 來源一致，依資料是否足夠決定分析用途

上傳題與存入題走同一個個人分析流程，不按來源預先排除。存入題沒有本人原作答很正常，不強制補填，也不把來源作者作答當成本人資料。

| 已有資料 | 可採用的部分 | 不足的部分 |
| --- | --- | --- |
| 科目＋題文／考點 | 收錄與考點分布 | 沒有本人作答時不推論本人錯因或掌握度 |
| 本人原作答＋正解＋相關題文 | 可比對原作答，提出可能混淆 | 不產生不存在的重作事件 |
| 已提交重作結果 | 重作次數、結果與同題變化；自評分開標示 | 沒有題文時只列數字，不解釋具體考點 |
| 缺正解 | 已有自評事件仍可統計，題文仍可做考點分析 | 不自動判選擇題正誤，不做依賴正解的錯因比較 |
| 缺科目 | 原功能維持 | 不納入目前科目分析 |

因此「不完整就不採用」細化為「哪項判斷缺依據，就不做那項判斷」。不是整題一律排除，也不是資料不齊仍讓 AI 推論。報告附各用途的可用數量及缺漏摘要，不增加題目確認狀態。

來源更新不打斷分析流程；使用者採用新來源後，下一份報告使用其目前個人版本。已完成報告與舊作答保留原依據，不默默重算。

## 4. 分析頁草案：待使用者批閱

### 4.1 操作順序

1. 進練習／分析，選科目，再選分析；可以再限制單元。
2. 分析該科目目前的個人題庫；作答觀察期間預設最近 30 天，可切換 7／15／30／60／90 天（使用者已核定）。先看統計及符合範圍的既有報告。舊題不因超出作答期間而排除。
3. 點「產生分析」才呼叫 AI；已有相同輸入的報告則直接重用。
4. 報告依有效資料量顯示有依據的考點／可能錯因，不固定三項，再顯示原題依據與「練習這些題」。資料不足時改呈現內容分布，不湊數。
5. 練習完成仍先看本輪結果；報告由使用者日後手動更新，不自動重算。

30 天是已核定的作答觀察預設，可選 7／15／30／60／90 天。不得因樣本少自動擴大使用者選定期間；題庫分布與重作事件期間分開定義。

### 4.2 顯示內容與缺資料降級

- 頁首：科目／單元、期間、報告截止時間、涉及題數與作答次數。
- 主要內容：有依據的考點與可能錯因，每項可查看相關原題；收錄量本身不能被標成能力弱點。
- 接續操作：建議原題練習，沿用 3／5／10 題設定、預設 5；不足時顯示實際可用數量。
- 展開資訊：AI／confirmed 組成、缺正解／缺本人原作答數、自評／自動判分數，以及原圖使用情況。
- 沒有重作：顯示收錄內容／考點分布，不出答對比例或進退結論。
- 只有少量事件：可以顯示實際分子分母，不能據此下穩定能力結論；至少同題有兩次才談該題結果變化。
- 新報告尚未生成時，當下統計與舊報告要各自標示時間，不能把舊解讀配新數字偽裝成同一份分析。

### 4.3 報告保存草案

| 資料 | 提議 |
| --- | --- |
| 逐次作答事件 | 不因報告到期刪除，持續保存至使用者刪題／刪帳號等明確資料清理 |
| 報告數字摘要 | 長期保存：科目、期間、樣本數、各單元分子分母、自評／自動組成、統計規則版本；不含題文與筆記 |
| AI 文字、引用題文與筆記快照 | 保留 90 天；到期清除詳細內容，只剩統計摘要與原報告時間 |
| 過期報告的歷史入口 | 仍可看統計摘要；明示詳細解讀已到期，不假裝可重現原 AI 報告 |

「長期保存」也服從使用者刪除與帳號清理，不承諾不可刪除的永久保存。範圍重疊的報告摘要不能相加當作新的作答總數；趨勢以事件計算。保留數字仍需要設計完整的刪題清理／失效規則，不藉摘要保留已刪除的個人內容。

### 4.4 答案提示草案

僅在缺答案、格式不一致或辨識明確表示無法判定時顯示小提示，點開可看具體原因。不能把「所有 ai 狀態」都標紅，也不能把模型自報的信心當成正確性保證。視覺採設計系統的低飽和提示，另附文字／可存取標籤，不單靠顏色。

### 4.5 自動混合抽題政策 v1

依使用者授權，由後端提出起始策略：在已限制的候選池，每次抽取先選策略再取尚未抽過的題。近期仍錯 40%、久未重作 30%、從未重作 20%、其他隨機 10%；池空時將權重按比例分配給其他非空策略。近期仍錯指最近 30 天最後有效結果仍錯；久未重作指至少 7 天未重作、且不屬前一組；其他隨機保留所有剩餘合格題的機會。同輪不重複。

這是長期抽取機率，不保證 5 題剛好分成固定比例。設定保存 policy version，可調整且不改寫舊紀錄。參考 Anki 對近期失敗、最久未看、隨機及不同篩選組合的支持；上述百分比與天數是 Redolve 的可調初值，不是 Anki 的公式，也不是已驗證的最佳值。[Anki 官方 filtered decks 說明](https://docs.ankiweb.net/manual/filtered-decks)

## 5. 下次只需批閱的事項

1. 裁切是否採「原題留 A、另建 B／C」，以及新題是否帶區域內筆跡。
2. 分析草案最多三項解讀是否合適；7／15／30／60／90 作答期間與預設 30 天已核定。
3. 作答與數字摘要長期留存、AI 詳細報告保留 90 天是否合適。
4. 答案小提示的觸發條件與原圖倍率，於連續畫面原型確認。

離開練習不續做、來源更新沿用刷題頁，已不再列為待決問題。
