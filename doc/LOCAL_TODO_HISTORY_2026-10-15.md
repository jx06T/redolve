## 如何查看

1. 使用本地前端與本地 Worker，登入上述帳號。
2. 待辦小組件三點菜單 → 重新同步（也可等待 40 秒快取到期再重新開啟）。
3. 今天完成留在目前清單；前六天的項目位於清單上方，向上捲動穿過緩衝區即可查看，或按「查看已完成」。
4. 今天完成的事項可再次點勾取消；只有昨天以前的已完成歷史項目不能直接取消勾選。點刪除左側的恢復圖示，經內建對話框確認後才移回目前待辦；取消對話框不改資料。

## 重建與清除

```powershell
Set-Location D:\Document_J\redolve
node .\scripts\seed-local-todo-history.mjs
```

依執行當天的臺灣日期建立最近七天測試資料，同日重跑不新增重複 ID，也不重置已操作的測試項目。自動選擇唯一已有非測試小組件資料的帳號；有多個候選時停止，需用 `--user 帳號ID` 指定。腳本只接受本地操作。

清除測試資料：

```powershell
node .\scripts\seed-local-todo-history.mjs --clear
```

只刪除該帳號固定測試 ID 前綴的項目（包括已恢復／改名的測試項目），保留原有待辦與倒數。每次寫入前會備份並核對原有列；清除後可再執行建立指令，刷新日期。自然超出保留期限的已完成測試項目仍由既有清理規則處理。
