## 路由與權限契約

- `/explore`：公開且可探索、尚未訂閱的內容；訂閱操作必須明確觸發。
- `/extended`：僅列明確訂閱集合；訂閱本身不新增觀看權限。
- `/collections/:id`：既有集合連結、邀請及未訂閱限定集合的相容入口。避免將非公開內容導到公開探索，也不隱式訂閱。
- `/collections/:id/items/:entryId`：單題唯讀分享；接收者必須通過既有集合及題目 API 的 ACL 檢查。不建立共用書寫控制器。
- `/settings/collections/:id`：集合管理；與觀看、私人訂正的操作目的不同。
- `/study`：自己的原題、已存版本與可貢獻集合的書寫及個人進度。
- 已存版本是取得時的內容與署名；改名不改寫既有下載。重新取得來源內容時才更新參考資料，私人訂正仍保留。
