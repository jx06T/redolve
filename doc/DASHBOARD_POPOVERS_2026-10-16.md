# Dashboard 彈出介面

## 分工

| 內容 | 呈現 |
| --- | --- |
| 待辦／事件倒數／學習計畫三點操作 | 靠觸發按鈕的非模態小面板，無全頁遮罩 |
| 待辦刪除／歷史恢復確認 | 靠該列按鈕的小型確認，不重複事項內容，預設焦點在取消 |
| 待辦完整整理說明 | 原有置中對話框；返回可重開原處選單 |
| 倒數／計畫編輯、同步衝突版本比較 | 原有置中對話框 |

共享 TodoRow／WidgetHeader 的設定頁同步採用本規則；未全域改動 AppDialog。

## 定位與關閉

- 外層與操作列圓角縮為 8px（依使用者要求）；選單使用 135deg 白至淡藍漸層 #FBFBFB → #EAF1FA，深色 #28282C → #293344，懸停 #DEE9F6／#36465B，與卡片底色分離；不恢復邊框或外層留白。

- AnchoredPopover 以 body portal、fixed 定位，避免 Dashboard 橫向滑頁、卡片與待辦捲動區裁切。預設以觸發按鈕左邊為起點向右下展開，右側空間不足時改為與按鈕右邊對齊向左展開；下側空間不足改上方，面板寬／高限制在可見範圍內；長內容在面板內捲動。刪除確認不顯示標題，取消／刪除上下排列，刪除用灰紅色；保留隱藏標題提供輔助技術名稱，來源列暫時淡紅背景與文字，恢復確認來源列淡綠；關閉／取消即清除。手機也維持小面板，不放置偏側的大型對話框。
- Navbar／BottomNav 的 data-overlay-edge 提供上下界，保持導覽可見；計入 visualViewport 的縮放／鍵盤範圍，預留 12px 畫面邊距，面板向按鈕透明點擊區內靠 4px，貼近可見圖示；操作選單寬 200px、確認選單寬 112px，兩者均無外框線、無外層 padding、無項目間隙，僅保留每項文字點擊內距，依可視寬度縮小。
- 點外側、Escape、焦點移出、捲動來源區域都收起。面板內捲動不收起；面板不是模態，不鎖背景。來源位置／內容或視窗尺寸改變會重算；來源已消失或不再可見時關閉。
- 開啟後才把焦點移入可見面板；操作選單可用上下鍵／Home／End 移動，Tab 不鎖住。Escape／取消返回來源；確認刪除該列時返回原清單。點其他操作時不搶回焦點。
- 三點選單、簡短確認共用定位／關閉／焦點行為。排序中可查看說明，關閉說明不取消編號或目的地步驟。

## 資料與驗證

- 只改前端呈現，不新增資料庫、API、快取或權限規則。開啟／關閉／取消不寫入；確認刪除／恢復、明確重新同步沿用原服務。
- tests/dashboard-popovers.browser.mjs：390／768／1280px，三類選單位置、上下導覽邊界、右下優先／右緣向左／下緣向上展開、緊湊尺寸、長內容、外側／捲動／Escape 關閉、鍵盤導航、焦點返回、刪除前不寫入／確認後只移除該題項，說明對話框與返回選單。
- 既有待辦排序與歷史恢復四組瀏覽器、TypeScript、建置／SW、PWA 回歸。瀏覽器使用合成 API；實體 iOS 縮放／鍵盤的最終手感待實機驗收。
